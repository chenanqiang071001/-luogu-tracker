# 洛谷 8 周刷题打卡 PWA

适用于安卓手机的轻量打卡网页。包含 8 周题单、洛谷直达链接、独立复做打卡、周笔记、统计、本地存储、JSON 备份与恢复，以及离线缓存。无需后端。

## 免费部署：GitHub Pages

1. 注册或登录 GitHub，在网页上新建一个 **Public** 仓库，例如 `luogu-tracker`。
2. 把本文件夹内的 **全部文件** 上传到仓库根目录（不是只上传 ZIP 文件，也不要多套一层 `luogu-pwa` 文件夹），提交 Commit。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选 **Deploy from a branch**，分支选 `main`、文件夹选 `/ (root)`，点击 **Save**。
4. 等待 GitHub Pages 部署完成，打开显示的 HTTPS 地址，通常是 `https://你的用户名.github.io/luogu-tracker/`（请以 Pages 页面显示的实际地址为准）。
5. 安卓 Chrome 打开该地址，点击右上角 **⋮ → 安装应用** 或 **添加到主屏幕**，按提示操作。部分浏览器会显示不同选项。网页内也可能出现“安装到桌面”按钮。

GitHub Pages 对公开仓库通常免费；需遵守 GitHub 当前的使用政策和额度。部署地址必须是 HTTPS（GitHub Pages 默认支持）。首次打开需要联网；安装和缓存完成后，可离线查看计划和打卡，但洛谷题目需要联网。

## 本地测试

在项目目录运行 `python -m http.server 8000`，电脑浏览器访问 `http://localhost:8000`。本地服务器适合功能预览，正式安装请使用 HTTPS 部署。

## 数据安全

打卡数据只存在当前浏览器的 localStorage 中，不会自动同步到 GitHub，也不会跨浏览器/手机同步。清除站点数据、卸载某些浏览器或换设备可能导致数据丢失。建议每周点击 **导出 JSON 备份**，保存到安全位置；恢复时使用 **导入 JSON 备份**，注意它会覆盖当前记录。

## 题单说明

共 42 个打卡任务，包含重复题目用于复做，不等于 42 道不同题目。题单主要面向基础训练；部分题目为进阶挑战。可以按照掌握程度调整进度。

## 更新说明

修改网页代码后，建议将 `sw.js` 的 `CACHE` 名称由 `luogu-tracker-v1` 改为新版本号，以刷新离线资源。打卡数据的 localStorage 键不需要更改。
